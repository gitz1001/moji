Privacy Policy — Moji Typing Sounds

Last updated: October 28, 2026 (v1.2.1)

Overview

Moji Typing Sounds ("the Extension") is a lightweight Chrome browser extension that generates synthesized typing sounds on keystrokes. Privacy and security are fundamental principles of the Extension.

Data We Collect

ZERO DATA COLLECTION We do not collect, log, or transmit any personal data.

The Extension does not collect, track, store, or transmit any personally identifiable information, browsing history, website URLs, website content, or typing data.

  • No Keystroke Logging: The Extension never records, logs, or stores typed characters. Keystrokes are used exclusively at the instant of input to trigger local procedural Web Audio synthesis.
  • No Keystroke Transmission: Typed characters are never transmitted to any server, third-party script, or DOM context. The Extension computes audio panning locally and discards key values immediately.
  • Password & Sensitive Field Protection: The Extension automatically detects password inputs (type="password"), credential fields (autocomplete="current-password", autocomplete="new-password"), one-time authentication codes, and financial/credit card fields. The Extension completely disables itself on sensitive fields: no keystroke processing occurs and no sounds are played.

Data We Store Locally

The Extension stores only three user preference values using Chrome's native chrome.storage.sync API:

  • Enabled state — whether typing sounds are active (boolean)
  • Sound pack — the name of the selected pack (text string, e.g., "mechanical")
  • Volume level — the user's preferred volume level (number between 0 and 1)

These preferences are stored in the user's personal Google Chrome sync storage and synchronized across their own Chrome browsers via Google's account sync. The Extension developer has no access to this data.

Third-Party Services & Remote Code

The Extension uses zero third-party services, analytics, external CDNs, or remote trackers.

All sound synthesis is procedurally generated locally on the user's device using the native Web Audio API. The Extension works 100% offline and loads no external scripts, styles, or fonts.

Permissions

  • storage — Used strictly to save and sync user preferences (sound pack, volume, enabled state).
  • Host Access on All URLs (Content Script) — Required solely to detect keyboard events and trigger real-time sound synthesis on web pages where the user is typing. The content script never reads, alters, stores, or transmits page content or typed text.

Data Sharing

We do not sell, rent, trade, or share any user data with third parties. No data is used for advertising, profiling, or monetization.
