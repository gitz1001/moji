## 💎 Phase 2: Moji Pro Monetization (v2.0)

### 🎙️ The Killer Feature: Custom Sound Creator
> *"Build your own keyboard personality."*

Most competitor extensions only provide a static dropdown of 3–5 generic switch samples. Moji's flagship paid feature will be a **Custom Sound Designer**:
- **Per-Key Mapping:**
  - Standard alphanumeric keys = `Deep Thock`
  - Spacebar = `Boom / Thud`
  - Enter key = `Typewriter Bell / Mission Complete`
  - Backspace = `Rewind / Crunch`
- **User Audio Uploads (Local IndexedDB):**
  - Drop your own `.wav` or `.mp3` samples.
  - Record voice snippets directly in the popup.
  - Meme sound packs (e.g., Vine boom, anime "nani", pop cat).
- **Pitch & Reverb Tweaker:**
  - Real-time Web Audio API pitch shift slider (make any sound high-pitched or bass-boosted).

## 📈 Chrome Web Store Growth Strategy

1. **Don't Monetize on Day 1:** Extensions with an early paywall get 1-star reviews ("Used to be good, now paywalled"). Free initial launch builds good faith.
2. **Organic Review Triggers:**
   - Trigger a polite rating prompt *only after positive milestones* (e.g., completing 5 practice tests or typing 5,000 keystrokes).
   - "Enjoying Moji? Leave a 5-star review on the Chrome Web Store to help us add more free packs!"
3. **SEO Keywords in Chrome Web Store:**
   - `mechanical keyboard sounds`, `typing sounds`, `thocky keyboard`, `typing practice`, `ASMR typing`.
4. **Community Co-creation:**
   - Run polls on Twitter/Reddit (`r/MechanicalKeyboards`, `r/productivity`) asking: *"Which switch sound should I synthesize next?"*
